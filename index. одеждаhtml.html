Возможности браузера

Ещё не проверено

Результат не содержит фото, его имени, постоянного ID устройства и оценки «готовности к ИИ». Отправка отчёта — только вручную.

Что проверяет эта страница

  1. Безопасный контекст HTTPS и доступ к WebGPU.
  2. Маленькое вычисление на GPU с проверкой ответа — не просто наличие кнопки или API.
  3. Выполнение простой WebAssembly-функции, WebGL и декодирование тестового изображения.

Что будет нужно для самой примерки

Совместимые мобильные веса, полный pipeline переноса одежды и реальный тест на обоих телефонах. Готового браузерного движка в этом файле нет.

Как передать результат

После проверки нажми «Скопировать отчёт» и вставь текст в чат. Либо скачай JSON и приложи его. Проверь оба телефона отдельно.
